# CHATBOT
Desenvolvendo um chatbot de IA que lê pdf diretamente em Python. (Projeto em Vibecoding.)

Para o desenvolvimento direto do nosso chatbot é necessário possuir duas coisas antes, primeiro uma IDE, aqui como era algo experimental utilizei o colab (da Google), depois de abrir nossa IDE, então conseguimos a chave API do nosso modelo. O que utilzei no experimento foi o Groq.
